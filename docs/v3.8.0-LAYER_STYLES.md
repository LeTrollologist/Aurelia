# v3.8.0 — Layer styles

Status: **shipped**. This is the written proposal the roadmap required before starting the first
P3 workstream, kept as the design record after implementation.

## Decision

Implement **stroke, drop shadow and outer glow** as **composite-time layer styles** on raster and
text layers.

- Styles are evaluated by the existing working-precision compositor every time the layer is
  drawn; nothing is baked into layer pixels.
- The style record lives on the layer (`Layer::styles`) and persists in a new optional AUR v3
  trailing section (`ASTY`). The v3 layer record and its header do not change, so existing files
  load unchanged and older builds simply ignore the new trailing section.
- The UI is a **Layer Styles** section in the right dock for the active layer, with a checkbox
  and controls per effect; one drag is one undo step.

## Why this scope

Layer styles are the smallest P3 item that exercises the architecture end-to-end (compositor,
storage, UI, undo, tests) without a renderer or format rewrite. The three effects share one
mechanism — derive a coverage mask from the layer's alpha, shape it (offset/blur/dilate), paint
it under or over the layer — so they ship together. More effects (inner shadow, bevel, gradient
overlay) can reuse the same mask pipeline later.

Out of scope for this release: inner effects, per-style blend modes, style presets/libraries,
styles on groups or adjustment layers (they have no pixels; the style record is ignored when
compositing those).

## Implementation

- `aurelia-core::layer_style`:
  - `LayerStyles { stroke, drop_shadow, outer_glow }`, serde-defaulted.
  - `render_styled(layer)` / `render_styled_srgb16(layer)` produce a layer-sized RGBA buffer in
    the layer's storage width: drop shadow (offset, separable box blur), outer glow (blur,
    restricted to `1 − alpha`), stroke (chamfer distance to the silhouette, coverage =
    `width − distance`), then the layer itself over the effects.
  - Masks, clipping, opacity, blend mode and offsets are untouched: the compositor substitutes
    only the pixels, so existing semantics carry over.
- Compositor: the 8-bit path draws a styled clone; the 16-bit path substitutes the styled
  `u16` pixels, evaluating effects at 16-bit even for an 8-bit layer in a mixed document.
- Persistence: `ASTY` section after `AED1`, length-prefixed, versioned, capped at 1 MiB,
  bounds-checked; absent or damaged sections are ignored rather than failing the load.
- Undo: `LayerStyleCommand` stores the before/after style records; the UI coalesces a gesture.
- UI: Layer Styles section with per-effect enable, width/offset/blur/radius/opacity sliders and
  sRGB colour pickers.

## Gates (all met)

| Gate | Evidence |
| :--- | :--- |
| No-style output byte-identical | Existing 702-case compositor oracle, digest and transform tests all pass unchanged. |
| Effects are non-destructive | Layer pixels are never rewritten; styles round-trip in the file and undo only changes the style record. |
| 8 and 16 bit | Composite tests assert the 16-bit path produces alpha outside the 8-bit lattice; layer format is preserved. |
| Format compatibility | New optional section; files without it load with default (empty) styles. Damaged section ignored. |
| No per-pixel allocation | Blur/distance masks are sized to the layer once per composite, allocated only when a visible style exists. |
| Cost | A styled layer pays mask blur(s) + a chamfer pass on its own bounds. Unstyled documents pay a single `styles.is_empty()` check per layer. |

## Limits

- Effects are clipped to the layer's bounds. Editor-created layers are canvas-sized, so this only
  clips at the canvas edge; a layer smaller than its effects will crop them.
- A style is recomputed per composite. For very large canvases with many styled layers this is
  measurable work; the style system is opt-in and the Navigator already throttles live rebuilds.
- Stroke is an outside stroke only; no inside/centre variants yet.

## Boundary policy (pinned in v3.8.1)

The style blur uses **transparent extension**: samples outside the layer buffer contribute zero
and the divisor is always the full kernel. A uniform mask therefore fades toward the border and
is unchanged in the interior, which is the right model for coverage that ends at the layer bounds
(the same result as evaluating the effect on a transparent-padded canvas). This is deliberate,
not a bug: the alternative (edge replication) would keep a uniform field uniform at the border
but is a different rendering semantic.

`layer_style::blur_policy` pins the interior, the left/right symmetry, corner ordering and thin
masks. If the product ever wants edge replication or normalized convolution instead, that is a
rendering change: change the implementation and these expectations together.

The vertical pass is row-major (per-column sums) and the pixel composites use one reciprocal;
both are output-preserving optimizations from v3.8.1. Style rendering still costs O(canvas �
effects); a content-bounds pass is the next optimization, tracked in the roadmap.
