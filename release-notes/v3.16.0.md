# Aurelia v3.16.0

## What this release means

Aurelia v3.16.0 adds a **read-only PSD import** path for 8-bit RGB Photoshop files. It is not a
PSD writer and not a claim of full Photoshop compatibility. Unsupported features reject the file
with an explicit error instead of importing a partial or silently flattened document.

The v3.15.0 preset library remains, and the v3.14.0 10-bit canvas path remains experimental,
opt-in and default-off.

## PSD support

Supported:

- PSD version 1 only
- 8-bit RGB
- raster layers
- nested groups
- layer masks with a matching mask channel
- opacity, visibility and clipping state
- common blend modes
- raw and PackBits RLE channel data
- composite fallback when there are no layer records

Rejected explicitly:

- PSB / version 2
- 16-bit and 32-bit documents
- grayscale, indexed, CMYK, Lab and duotone
- ZIP and ZIP-prediction channel data
- text layers
- adjustment/fill layers
- vector masks
- unknown additional-layer metadata blocks
- unknown blend modes
- layers outside the canvas
- malformed, truncated or oversized files

Limits: 512 MiB file, 32,768px side, 512 Mi pixels, 4,096 layers and a 1 GiB decoded budget.

## UI behaviour

`File → Open` accepts `.psd` with a read-only label. Imported PSDs open as unsaved documents, so
Save prompts for an AUR path and cannot overwrite the original PSD. Import failures use the normal
status/error path.

## Verification

- 399 Rust tests passing, 2 ignored.
- Formatting and Clippy correctness pass.
- Real PSD fixtures from the MIT-licensed `psd-tools` corpus:
  - supported: `0layers.psd`, `1layer.psd`, `2layers.psd`
  - expected rejection: `empty-group.psd`, `group.psd`, `layer_mask_data.psd`,
    `blend-and-clipping.psd`, `hidden-groups.psd`, `mask-density-layermask.psd`

Expected-rejection fixtures assert `Unsupported` and are not counted as successful imports.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against the published public key before running either binary. The installer
is not Authenticode-signed; Windows SmartScreen may warn.
