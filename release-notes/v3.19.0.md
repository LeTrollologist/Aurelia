# Aurelia v3.19.0

## What this release means

v3.19.0 closes the two gaps declared in the v3.18 notes: style presets can now be **renamed and
reordered** in the panel, and bevel/emboss gains **soften, contour and gloss** controls instead of
a single fixed profile. The ASTY payload moves to **version 3** for the new bevel fields.

## Style preset management

- Each preset row has select, **↑**, **↓** and **✕** actions. Selecting a row reveals a rename
  field; renaming rejects empty names, names over 200 bytes, and case-insensitive duplicates
  (a same-row rename to the same name is allowed).
- Order is the stored order: moving a preset swaps it with its neighbour and saves immediately,
  and the selection follows the moved row. Moving above the first or below the last row is a
  no-op.
- All mutations remain bounded and atomic: the library is revalidated and written through the
  same unique-temp/`sync_all`/rename path as before, and a failed save keeps the previous file.

## Bevel controls

- **Soften** (0..=1) widens the normal field to three times the bevel size at 1, spreading the lit
  band inward.
- **Contour** (-1..=1) reshapes the rim falloff: positive tightens the rim, negative broadens it.
- **Gloss** (0..=1) raises the lit side to a power of up to 4, concentrating the highlight into a
  sharper specular while leaving the shaded side unchanged.
- All three are deterministic (tested by rendering twice), preserve alpha exactly, and are
  clamped on read. Existing bevels load with all three at 0, which reproduces the previous output.

## ASTY version 3

- New builds read **v1, v2 and v3** and always write **v3**. The AUR v3 container is unchanged.
- Version 2 bevels load with `soften = contour = gloss = 0`, so a v3.18 project renders exactly as
  it did.
- Unknown versions are ignored as before; a build older than v3 drops the new controls if it
  resaves, which is stated in `docs/PROJECT_FORMAT.md`.

## Verification

- **454 Rust tests passing, 2 ignored.** New coverage:
  - preset rename/reorder persist across reload, duplicate and empty names rejected, moves
    clamped at both ends;
  - ASTY v2 bevel parses with the new controls at 0, v3 round-trips and clamps (soften/gloss to
    `0..=1`, contour to `-1..=1`), and a truncated v3 bevel is ignored;
  - soften widens the lit band, contour and gloss change the rim deterministically, alpha is
    unchanged in every case;
  - the existing randomized bounded/full equivalence suite now includes nonzero bevel controls.
- Formatting and Clippy correctness pass; no `f32` fallback warnings.

## Compatibility

- AUR project files remain AUR v3; only the optional trailing ASTY section changes version.
- Style presets remain `ASRP` v1; rename/reorder does not change the wire format.
- No change to 8-bit or 16-bit storage precision, and no effect is evaluated when disabled.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary. The
installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if any,
describe only the scanned artifacts and are advisory.
