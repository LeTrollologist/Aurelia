# Aurelia v3.9.0 — styled-layer performance: content bounds

Layer styles now render only where they can affect the image. A styled layer's effect passes are
confined to its non-transparent bounds, expanded by the exact reach of each effect, instead of
processing the whole canvas. Small artwork becomes effectively free; large artwork gets a solid
constant-factor win; output is gated to be bit-identical to the old full-canvas renderer.

## Results

`bench_styles`, same workload and effects at every layer count, 3 warm-up + 20 measured runs
(median). Raw samples: [docs/benchmarks/style-baseline.json](https://github.com/LeTrollologist/Aurelia/blob/main/docs/benchmarks/style-baseline.json).

| Document | Layers | Art | Before (style / composite) | After |
| :--- | --: | :--- | --: | --: |
| 1920×1080 | 1 | ~75% | 129 / 133 ms | **79 / 83 ms** |
| 1920×1080 | 4 | ~75% | 130 / 541 ms | **88 / 382 ms** |
| 1920×1080 | 1 | 10% | 129 / 133 ms | **3 / 8 ms** |
| 3840×2160 | 1 | ~75% | 551 / 588 ms | **355 / 367 ms** |
| 3840×2160 | 4 | ~75% | 526 / 2190 ms | **332 / 1457 ms** |
| 3840×2160 | 1 | 10% | 551 / 588 ms | **13 / 35 ms** |
| 3840×2160 | 8 | ~75% | 788 / 6415 ms | **348 / 2843 ms** |

The small-art case improves by roughly two orders of magnitude; large-art cases by 35–55%. Full
canvas art is deliberately unchanged: its bounds clamp to the canvas, so it pays the same work plus
one alpha scan.

## How

- `styled_rect` finds the layer's alpha bounds and expands them by the largest effect support:
  blur is three box passes with `kernel = max(1, round(radius/1.5))`, so `3·kernel`; shadow adds
  its offset; glow is the blur support; stroke is `ceil(width) + 1`. The rect is clamped to the
  canvas.
- `render_rect` is the single renderer, used both for the full-canvas reference and for the
  bounded path, so the effect maths did not fork.
- The styled buffer is still layer-sized; pixels outside the rect are transparent. The compositor
  already treats zero alpha as no contribution, so no compositor API change was needed.
- Mask caching is **not** included: the small-art path is already single-digit milliseconds and
  the remaining large-art cost is real effect work. It stays a documented option if a
  many-small-layers profile justifies it.

## Equivalence gate

The old full-canvas renderer is retained as the reference. Two test modules compare bounded output
against it:

- `bounded_equivalence`: empty layer, single pixel, corners, art touching each edge, full canvas,
  rectangles, with all effects — at both 8 and 16 bits.
- `bounded_randomized`: 24 deterministic pseudo-random fixtures with random alpha blobs, offsets,
  blur radii and effect combinations.

Every pixel with non-zero alpha must match exactly (RGBA); alpha must match everywhere; pixels
outside the rect must be transparent. The existing 702-case compositor oracle, digest suites and
all previous tests are unchanged.

## Limits and follow-ups

- Large art still costs thousands of milliseconds with many styled layers at 4K: eight styled
  layers at ~75% coverage are ~2.8 s per composite. That is real effect work, not bounds overhead.
- Full-canvas art gets no win by design.
- The output buffer is still allocated layer-sized; a compositor-level sub-rect overlay would save
  the zero fill, but the measurement does not justify the API churn yet.
- Style semantics (clipping to a styled base, Scale Styles, Merge Down) remain deliberately
  undecided; see the roadmap.

## Compatibility

- No format changes; AUR v3 files are unchanged.
- Styled output is unchanged wherever effects are visible; only the transparent region outside the
  effect support is now zeroed instead of carrying the layer's RGB with zero alpha (invisible to
  compositing and exports).
- Unstyled documents and non-style compositing are untouched.
