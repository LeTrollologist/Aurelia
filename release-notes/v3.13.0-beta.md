# Aurelia v3.13.0-beta — colour management preview

**This is a beta, not a production release.** It is the first build with document colour profiles,
so the colour pipeline and its interactions are still under validation. Keep v3.12.0 for production
work.

## ICC profiles

- Documents can carry an ICC profile. **Assign** changes interpretation without touching pixels;
  **Clear** returns to untagged sRGB.
- **Convert to sRGB** / **Convert to ICC** are the only operations that move pixels. One undo step
  restores every raster/text layer and the profile together.
- Untagged documents keep the existing sRGB behaviour byte-for-byte.
- The engine is `moxcms` (pure Rust): 8- and 16-bit RGBA transforms, profile validation, and exact
  profile-byte retention for round-trip.

## Persistence and interchange

- AUR v3 has an optional trailing `AICC` section; damaged or absent sections load as untagged.
- PNG embeds `iCCP`, JPEG embeds APP2, and WebP is upgraded to a `VP8X` container with `ICCP`.
- Import reads profiles back from PNG/JPEG/WebP. Opened images keep their profile on the document;
  reference images convert into the document working space instead of being treated as sRGB.

## Soft proofing

- RGB proof profiles can be previewed through the **SOFT PROOF · approximate 8-bit** badge.
- The proof transform is cached by document revision, canvas size, proof hash and document-profile
  hash, so pan and zoom do not re-run it.
- This is a simulation on the 8-bit viewport, not a wide-gamut display claim.

## Known limits in this beta

- **CMYK proofing is not implemented.** Only RGB proof profiles are accepted.
- The viewport remains 8-bit sRGB presentation; 10-bit output is the separate DXGI track and still
  needs 10-bit hardware for its visible gate.
- JPEG/WebP profile support covers RGB ICC profiles; unusual profile classes may be rejected.
- Windows installers remain unsigned by permanent policy; VirusTotal results are heuristic.

## Verification

- 355 Rust tests passing (2 ignored: soak and sparse gate); clippy clean.
- `python scripts/quality.py`: workspace, release-tool pytest, sparse gate and soak.
- No AUR format bump; files without `AICC` load exactly as v3.12.0 wrote them.
