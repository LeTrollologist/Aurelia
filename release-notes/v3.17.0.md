# Aurelia v3.17.0

## What this release means

v3.17.0 is a correctness and reliability release with one new feature. It hardens the Win32
message boundary, makes the document lifecycle honest about unsaved work, keeps canvas geometry
(including layer masks) consistent through resize, rotate and save, fixes two 16-bit/10-bit
compositing defects, and adds installed system fonts to the text tool. The PSD importer's
budgets are now actually enforced, and a damaged or hostile project file can no longer make the
application abort on allocation.

The v3.16.0 read-only PSD import, the v3.15.0 preset library and the opt-in, default-off 10-bit
canvas path are unchanged.

## Security and robustness

- `WM_NCCREATE` installs the window's state pointer once, only from the window-creation path. A
  repeated message — deliverable by any same-user process — can no longer replace it with an
  arbitrary pointer.
- `WM_DESTROY` no longer frees the application state. The message loop owns it and frees it
  after the last dispatch, so a forged destroy cannot free memory a live frame is using.
- A `WM_PAINT` re-entered by a modal dialog only validates its region instead of aliasing the
  live application state; a panic inside a message handler stops the message loop rather than
  unwinding into `user32`; a `GetMessageW` error is no longer treated as a clean exit.
- PSD: every canvas-sized buffer is charged to the decoded-byte budget before allocation, and
  channels the importer does not use are skipped without decompression. A small RLE file could
  previously force multi-gigabyte allocations (up to ~28 GiB with 56 channels).
- Project files: an `active_layer_id` of `u64::MAX` is rejected instead of overflowing the
  next-layer id, and a layer mask that does not match the canvas is refused by name rather than
  silently written as "no mask".
- Export no longer deletes an existing destination before renaming; a failed rename leaves the
  previous export in place.

## UI lifecycle

- Every dialog that ran inside the egui frame (preset import/export in both panels, the two
  custom-font pickers, Recent Projects) now runs through the host after the frame. A modal that
  pumped the message queue could previously re-enter the UI with a second mutable borrow of the
  application state.
- New Canvas, File → Open, Recent Projects and drag-and-drop all ask before discarding unsaved
  changes; previously only closing the window did.
- Recent Projects opens imported PSDs as unsaved documents, so Save cannot overwrite the
  original PSD, and it loads through the same path as File → Open.
- Crash recovery asks once and lists every snapshot found, instead of one dialog per file.
  Answering No discards all listed snapshots; Yes tries the newest first.

## Canvas, masks and colour

- Layer masks now follow `resize_canvas`, `scale_canvas`, `flip`, `rotate_90` and
  `Document::resize` with the same kernel as the pixels. Previously a resize read the mask at
  the new stride (wrong coverage) or dropped it, and the next save deleted it.
- PSD import expands each raster layer into a canvas-sized buffer at its offset — the layout the
  AUR format stores — so imported PSDs with sub-canvas layers can be saved and reloaded. Layer
  masks are placed in a canvas-sized mask, and the PSD mask-invert flag is honoured.
- The 16-bit adjustment pass reads its clipping base with the base layer's own dimensions. It
  previously used the canvas stride, which produced the wrong clipped alpha whenever the base
  layer was smaller than the canvas.
- The 16-bit viewport samples the proofed framebuffer in both its bilinear and nearest branches,
  so soft proof is visible at 1:1 and above 2.5× zoom.

## Typography

- The text tool lists the fonts installed for the machine (read from the Windows font registry,
  sorted and de-duplicated by family) in the toolbar's font menu, alongside the file picker.
  `.ttc` collections are skipped because the rasterizer cannot load them.
- Clicking away from the text box being edited now commits it instead of stacking another text
  layer; a new type layer starts empty; a click inside an existing box (or within 8 screen
  pixels of its edge) selects and drags it; and an empty type layer is discarded on commit.

## Verification

- 415 Rust tests passing, 2 ignored.
- Formatting and Clippy correctness pass; the workspace build is warning-clean in the touched
  crates (the pre-existing `f32` literal and unused Win32 import warnings remain).
- New regression tests: PSD RLE amplification and unused-channel skipping, PSD mask placement
  and round-trip, mask transforms, `u64::MAX` active layer id, export replacement, 16-bit
  clipped adjustment parity, soft proof in the 16-bit viewport, system-font registry parsing and
  enumeration, and text commit/discard semantics.
- UI lifecycle was exercised with a local Win32 harness against the built binary: unsaved-work
  prompts on New/Open/Recent/drop, PSD read-only import, Save As on an imported PSD, preset and
  font dialogs outside the frame, and the close guard.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary.
The installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if
any, describe only the scanned artifacts and are advisory.
