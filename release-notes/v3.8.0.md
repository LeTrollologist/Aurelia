# Aurelia v3.8.0 — layer styles

This release opens the P3 phase with its smallest end-to-end feature: **non-destructive layer
styles**. A layer can now carry a stroke, a drop shadow and an outer glow that are evaluated when
the document is composited, not baked into its pixels.

## Layer styles

- **Stroke**, **drop shadow** and **outer glow**, each with width/offset/blur/radius, opacity and
  an sRGB colour picker in a new **Layer Styles** section for the active raster or text layer.
- Effects are computed from the layer's own alpha silhouette and composited under/over the layer
  in the existing working-precision compositor. Layer masks, clipping, opacity, blend mode and
  offsets keep their exact meaning; the layer's pixels are never modified.
- Works at both storage widths. A styled RGBA16 layer keeps its format, and an 8-bit layer inside
  a mixed document is styled at 16-bit precision so the glow does not quantise to the 8-bit
  lattice.
- **Undo is gesture-scoped:** dragging a slider produces one `Layer Style` step, and undo restores
  the exact previous stack (including which effects were enabled).

## Persistence without a format bump

Styles are stored in a new optional, length-prefixed section after the editor block:

```
"ASTY" | u32 payload length | version u8 | count u32 | entries...
```

Each entry carries the layer id, a flag byte and only the fields of the enabled effects. The AUR
v3 layer record and header are unchanged, so files without the section load with empty styles,
older builds simply stop reading earlier, and a damaged or truncated optional section is ignored
instead of failing the load (bounded to 1 MiB, 100 000 entries, finite floats, clamped opacity).

## Gates

| Gate | Evidence |
| :--- | :--- |
| No-style output byte-identical | The 702-case compositor oracle, digest and transform suites pass unchanged. |
| Non-destructive | Save/load round-trip of the style stack; undo modifies only the style record. |
| 8 and 16 bit | Composite test asserts sub-lattice alpha from a styled 16-bit composite; layer format preserved. |
| Format compatibility | `ASTY` is optional and additive; damaged sections are ignored. |
| Cost scoped to styled layers | Unstyled layers pay one `styles.is_empty()` check per composite; masks are allocated only when a visible effect exists and are bounded by the layer's size. |

Design and limits (effects are clipped to layer bounds, stroke is outside-only, styles are
recomputed per composite): [docs/v3.8.0-LAYER_STYLES.md](../docs/v3.8.0-LAYER_STYLES.md).

## Compatibility

- AUR v1/v2 load read-only; saves continue to write v3. Existing v3 files are unchanged and load
  with no styles.
- No document-format bump; no change to existing layer fields or blend bytes.
- Groups and adjustment layers have no pixels, so a style attached to one is ignored at composite
  time (the file still stores it).
