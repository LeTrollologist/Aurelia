# Aurelia v3.17.1

## What this release means

v3.17.1 is a patch release for the layer panel and one untested fix from v3.17.0. Deleting a
layer, adding or duplicating one, changing a mask, or toggling visibility/blend/folder
membership could leave the document looking unmodified: closing the window never prompted, and
an undo after a delete could not bring the layer back. Those operations are now undoable steps
that mark the document dirty, and the Copy Merged stale-selection panic that v3.17.0 fixed is
now covered by a regression test.

Everything else from v3.17.0 is unchanged.

## Layer panel: undo and dirty tracking

Undoable, one step each, and dirty by construction:

- delete a layer or a folder (with every descendant and its pixels);
- add a raster layer, a folder, a layer inside a folder, or an adjustment layer;
- duplicate a layer or a folder with its descendants;
- create a mask from the selection, invert it, enable/disable it, remove it;
- toggle layer visibility, change the blend mode, remove a layer from its folder.

Two known gaps remain open and are listed here rather than implied fixed:

- **Ungrouping** marks the document dirty but has no undo step yet; its children lose the
  folder and an undo would have to restore the folder and every child's parent id.
- **Continuous property edits** — renaming a layer, dragging the opacity slider, and editing
  adjustment values — mark the document dirty (so Save and the close prompt see them) but each
  change is not yet a discrete undo step.

The undo budget now accounts the layer pixels retained by add/delete commands, so a document
full of large layers cannot hold more structural history than its budget allows.

## Copy Merged

`Copy Merged` slices the composite using the selection bounds. A selection can outlive the
document it was made in (Open, canvas resize, crop), and v3.17.0 clamps those bounds to the
canvas. That clamp was shipped without a test; v3.17.1 adds it, and reverting the clamp makes
the test panic with `range end index 16528 out of range for slice of length 16384`, which is the
original defect.

## Verification

- 421 Rust tests passing, 2 ignored (six new layer-lifecycle tests).
- Formatting and Clippy correctness pass.
- New tests: Copy Merged with a selection larger than the canvas; delete undo restores a layer
  and a folder's children; add/duplicate undo; mask and visibility undo with dirty checks;
  ungroup dirty check; the undo budget change is exercised by the existing history tests.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary.
The installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if
any, describe only the scanned artifacts and are advisory.
