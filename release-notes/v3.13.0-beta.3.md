# Aurelia v3.13.0-beta.3 - project, clipboard and IPC hardening

**This is a prerelease.** It fixes the remaining project-name, clipboard and Discord IPC
hardening issues from the audit.

## Layer name length

AUR v3 stores a layer name length as a `u16`. The writer now rejects a name longer than
65,535 UTF-8 bytes with `TextFieldTooLong` instead of writing a wrapped length and producing
an unloadable project. The layer-name field in the Layers panel truncates at a UTF-8
character boundary, and autosave uses the same writer validation.

The boundary case (exactly 65,535 bytes) round-trips; the oversized case is rejected before
the name record can be written.

## Clipboard text handling

`CF_UNICODETEXT` reads are now bounded by `GlobalSize`. A block with no NUL terminator inside
its allocation is rejected instead of being scanned past its end. `set_clipboard_text` now
checks `EmptyClipboard`, `GlobalAlloc`, `GlobalLock` and `SetClipboardData`, returns failure
accurately, and frees the block when clipboard ownership was not transferred.

The UTF-16 decoding helper has regression tests for unterminated, empty and first-terminator
blocks.

## Discord IPC READY frames

The 1 MB frame limit used by normal polling now also applies to the initial READY frame.
READY must be a FRAME (opcode 1); the frame length is validated before allocation, and the
header/body reads are bounded by the handshake deadline so a partial frame cannot block
indefinitely.

## Verification

- 373 Rust tests passing, 2 ignored (sparse gate and soak), including new name-boundary,
  clipboard and IPC regression tests.
- The release tool's pytest suite includes the no-VirusTotal-key notes case.
- No AUR format bump; existing valid projects continue to load unchanged.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed and SHA-256 verified.
The installer remains unsigned by Authenticode policy; Windows SmartScreen may warn.
