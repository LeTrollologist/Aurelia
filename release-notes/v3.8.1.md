# Aurelia v3.8.1 — layer-style reliability

This is a bug-fix release for the v3.8.0 layer styles. It fixes two data-loss-adjacent problems
in the style editing transaction, pins the blur boundary policy, removes a per-frame buffer copy,
and corrects clipboard DIB channel handling. No new features.

## Fixed

### Style edits now register as unsaved changes

Moving a style control modified the document while the undo command was only recorded at the end
of the gesture, and neither the edit nor the open gesture touched dirty tracking. Closing Aurelia
mid-gesture could discard the edit without an unsaved-changes prompt, and autosave considered the
document clean.

The open gesture now marks the document dirty immediately, and saving resolves the pending
gesture before the saved generation is recorded, so a save followed by no further edit is not
immediately dirty again.

### Style-edit transactions commit reliably

- **Keyboard and wheel changes** on a slider produced no history entry until an unrelated mouse
  release; they now commit on the frame they change.
- **Switching layers** during a drag abandoned the previous transaction (the styles stayed in the
  document but could not be undone). The open gesture is committed before the new one begins, and
  leaving the layer also closes it.
- **Save (including Save As)** closes the open gesture first, keeping history and saved-state in
  sync.

One gesture remains one undo step: `Layer Style` restores the exact previous stack.

### Blur boundary policy defined and pinned

The style blur uses **transparent extension**: samples outside the layer contribute zero and the
divisor is the full kernel, so a uniform mask fades near the border and stays uniform in the
interior. That is the correct model for a layer whose coverage ends at its bounds (the same result
as computing the effect on a transparent-padded canvas), not an artefact.

The implementation was also rebuilt to be cache-friendly: the vertical pass now walks rows with
per-column sums instead of striding down columns, and the per-pixel composites use one reciprocal
instead of three divisions. Output semantics are unchanged. New tests pin the interior,
edge symmetry and thin-mask behaviour.

### Styled-layer compositing no longer clones the layer buffer

`Layer::with_buffer` used `clone()` and then replaced the buffer, copying the full pixel buffer
(and mask) per styled layer per composite. It now copies metadata only. The style renderer remains
the dominant cost (see below); removing the copy is a small but free win.

### Clipboard DIB channel masks and alpha

`decode_dib` accepted `BI_BITFIELDS` but ignored the masks and always assumed BGRA, and it rewrote
an all-zero alpha channel to opaque even when an alpha mask was explicitly present. It now honours
R/G/B/A masks (including masks that follow a 40-byte header), scales sub-8-bit channels, and only
applies the "alpha unused" heuristic to plain 32-bit `BI_RGB` images. Regression tests cover
RGBA-ordered masks, explicit alpha masks and the 40-byte-header layout.

## Performance — measured, not assumed

`cargo run --release -p aurelia-render --example bench_styles`, reference machine, median of 12
runs. Full numbers are in [docs/PERFORMANCE.md](../docs/PERFORMANCE.md).

| Document | Layers | Style render | Composite | Viewport | Navigator |
| :--- | --: | --: | --: | --: | --: |
| 1920×1080 | 1 | 141 ms | 143 ms | 150 ms | 1.8 ms |
| 1920×1080 | 4 | 121 ms | 499 ms | 508 ms | 1.7 ms |
| 3840×2160 | 1 | 500 ms | 508 ms | 573 ms | 1.8 ms |
| 3840×2160 | 4 | 502 ms | 2091 ms | 2212 ms | 1.8 ms |

The row-major blur and reciprocal changes cut the 1-layer 4K composite from ~1109 ms to ~508 ms
and the 4-layer case from ~4676 ms to ~2091 ms versus the v3.8.0 implementation on this machine.
The buffer-copy removal is inside the noise of the style render.

**This remains expensive.** Style rendering is still O(canvas × effects) and dominates styled
composites; with several styled layers the viewport is not interactive at 4K. A follow-up should
render effects only inside the content bounds expanded by the largest effect radius (and consider
u8/u16 mask passes); that is a separate, benchmarked change, not part of this reliability fix.

## Decisions still open (not in this release)

- Clipping a layer to a **styled base**: the clip currently uses the base's raw alpha, ignoring its
  stroke/glow/shadow. Needs a product decision on clipping semantics.
- **Canvas scaling** does not scale style width/radius/offset; a "Scale Styles" option is the
  likely answer.
- **Merge Down** (core API; not exposed in the UI) composites raw pixels and would drop styles;
  fix before exposing it.
- 8-bit paletted DIB import remains unsupported (rejected, not mis-decoded).

## Compatibility

- AUR v1/v2 read-only; v3 saves unchanged. No format changes in this release.
- Clipboard images written by other applications with explicit masks now decode correctly; BGRA
  and 24-bit inputs are unchanged.
- Style output is unchanged except where the cache-friendly blur differs by f32 rounding; the
  policy tests are the guard.
