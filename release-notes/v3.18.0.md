# Aurelia v3.18.0

## What this release means

v3.18.0 is the layer-style extension. The composite-time style stack, which shipped with stroke,
drop shadow and outer glow, now also carries **inner shadow**, **inner glow** and **bevel/emboss**,
with a separate **style preset library** and an explicitly versioned ASTY payload. Everything is
additive: no renderer rewrite, no document-format change at the container level, no new
dependency.

## New effects

- **Inner shadow** — inverse silhouette, offset and blurred, clipped by the layer's own alpha.
- **Inner glow** — inverse silhouette blurred at a radius and clipped inward.
- **Bevel / emboss** — deterministic edge normal from the gradient of a blurred silhouette, lit
  from an adjustable angle (225° = upper-left), with separate highlight and shadow colours and a
  depth control.

Invariants enforced by tests:

- Inner effects **tint the pixels the layer already covers and never change alpha**. The layer's
  silhouette, including fractional coverage, survives every effect untouched.
- Inner shadow coverage is `blurred_inverse × alpha`, so a half-transparent pixel takes half the
  shadow rather than being treated as a binary mask.
- Holes and disconnected islands produce their own local normals; a one-pixel detail is finite and
  deterministic (rendered twice, byte-identical).
- RGBA8 and RGBA16 have **equivalent effect behaviour** (same direction, same clipping, same
  relative strength); they are not required to be byte-identical across storage precisions.
- The bounded renderer equals the full renderer for randomized fixtures containing all six
  effects. Inner effects needed the same support margin as outer effects because they blur the
  inverse silhouette; the support calculation was corrected and is covered by that suite.

Existing effect digests did not move: the opaque path is unchanged, and the scale-canvas baselines
still pin the previous bytes.

## ASTY version 2

- New builds read **v1 and v2** and always write **v2**. The AUR v3 container is unchanged; ASTY
  remains an optional trailing section.
- Unknown ASTY versions are ignored, so the document still loads without styles.
- **Compatibility caveat:** a build older than v2 ignores the section; if that build saves the
  project, the new effects are dropped. This is documented in `docs/PROJECT_FORMAT.md` and is the
  same forward-compatibility rule as any unknown trailing section.

## Style presets (`styles.aurp`)

A separate library from `presets.aurp`, so a style-schema change can never invalidate brush or
gradient presets:

- Bounded and atomic: 256 presets, 200-byte names, 64 KiB JSON, 2 MiB payload; unique sibling
  temp file, `sync_all`, rename; a failed save leaves the previous library and removes its temp.
- Version 1 is the only accepted version; unknown versions produce an explicit error.
- Panel: save the active style stack under a name (an existing name is replaced), apply any preset
  as one undoable style edit, delete, and import/export the library.

## Performance baseline

The pre-feature benchmark (`bench_styles`, 20 measured runs) recorded 4.13 ms style pass for the
1080p small-art fixture and 15.03 ms for 4K small art; large-art style passes are 98 ms at 1080p
and 515 ms at 4K. These numbers and the exact conditions are in
`docs/style-extensions.md`. New effects are optional per layer, so documents without them pay
nothing, and the existing digest suite confirms their output is unchanged.

## Verification

- **448 Rust tests passing, 2 ignored** (six new effect tests, five style-store tests, ASTY v1/v2
  compatibility, preset save/load/apply/undo).
- Formatting and Clippy correctness pass; no `f32` fallback warnings.
- Project format tests: v1 payloads load with the new effects `None`; v2 round-trips; an unknown
  version is ignored.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary. The
installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if any,
describe only the scanned artifacts and are advisory.
