# Aurelia v3.17.3

## What this release means

v3.17.3 makes ungrouping a folder reversible. v3.17.1 and v3.17.2 made the layer panel's
structural edits and toggles undoable; ungroup was the one remaining panel operation that only
marked the document dirty. It is now a single history step: undo restores the folder at its
original index and re-parents its direct children to it, redo releases them again.

Everything else from v3.17.2 is unchanged.

## Layer panel

- **Ungroup is undoable.** The step captures the folder layer and its index, the parent its
  children are released to, and the ids of those direct children. Undo reinserts the folder and
  restores each child's parent; redo removes the folder and re-releases the children. Nested
  folders behave the same: ungrouping an inner folder moves its children into the outer folder,
  and undo returns them to the inner folder.

Still open, listed rather than implied fixed:

- **Continuous edits** — renaming a layer, the opacity slider and adjustment values — mark the
  document dirty but are not yet discrete undo steps, and a slider drag is one dirty flag rather
  than one coalesced undo entry.

## Verification

- 424 Rust tests passing, 2 ignored (new: ungroup undo/redo with the folder's index and child
  ownership, and a nested-folder case).
- Formatting and Clippy correctness pass.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary.
The installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if
any, describe only the scanned artifacts and are advisory.
