# Aurelia v3.13.0-beta.4 - durability, quality and import hardening

**This is a prerelease.** It closes the remaining audit findings around save durability,
verification claims and aggregate import memory.

## Durable project saves

Project saves now write to a unique sibling temporary file (process id, timestamp and sequence),
call `sync_all` before replacing the destination, and clean the temporary file if any step fails.
The previous destination is left intact when serialization, synchronization or replacement fails.
Parent-directory synchronization is attempted where the platform supports opening a directory.

## Quality gate and documentation

- `cargo fmt --all -- --check` is now blocking.
- `cargo clippy --workspace --all-targets -- -D clippy::correctness` is blocking; style warnings
  remain advisory under the documented policy in `docs/QUALITY.md`.
- The two denied `erasing_op` lints are fixed.
- The workspace declares `rust-version = "1.87"`, README now advertises Rust 1.87+, and
  `rust-toolchain.toml` pins the stable toolchain with clippy and rustfmt.
- ICC documentation now reflects PNG `iCCP`, JPEG `APP2` and WebP `ICCP` support.
- `SECURITY.md` points at the current prerelease.
- `releases/ledger.json` is the public machine-readable index for releases from v3.0.2 onward;
  `scripts/rebuild_release_ledger.py` regenerates it.

## Brush import budget

Brush imports now have an aggregate decoded budget of 63 Mi pixels / 252 MiB, charged at four
bytes per pixel before a stamp's alpha buffer is allocated. One stamp remains capped at
4096 x 4096 and one file at 256 stamps; a fourth full-size 4096 stamp is rejected. Gradient
presets are fixed enum settings with no file payload, so they have no separate import allocation.

## Verification

- 376 Rust tests passing, 2 ignored (sparse gate and soak).
- `python scripts/quality.py` runs formatting, Clippy correctness, the workspace suite, the
  release-tool pytest suite, the sparse-16-bit gate and the 120-cycle soak.
- No AUR format bump; existing valid projects continue to load unchanged.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed and SHA-256 verified.
The installer remains unsigned by Authenticode policy; Windows SmartScreen may warn.
