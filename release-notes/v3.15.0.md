# Aurelia v3.15.0

## What this release means

Aurelia v3.15.0 adds a durable brush and gradient preset library. Presets now survive restarts and
are stored in a versioned, bounded file instead of being limited to the current session.

The experimental 10-bit canvas presentation from v3.14.0 remains **opt-in and default-off**. This
release does not claim verified 10-bit scanout.

## Preset library

- Location: `%LOCALAPPDATA%\Aurelia\presets.aurp`.
- Header: `AURP` magic and version 1.
- Bounded: 512 brush presets, 512 gradient presets, 4,096-byte strings, 256 KiB JSON records,
  8,192px stamp side, 63 Mi pixels aggregate stamp coverage and a 256 MiB decoded budget.
- Bad magic, unsupported versions, malformed UTF-8, truncation, trailing bytes, invalid stamp
  dimensions and oversized data are rejected explicitly.
- Future versions must add a migration before `PRESET_VERSION` changes; unknown versions are never
  reinterpreted.

## Durability

- Unique sibling temporary file, `sync_all`, atomic replacement and cleanup on failure.
- A failed save leaves the previous preset file intact.
- Startup loads presets after preferences; a missing file keeps the factory library, while a
  corrupt file is reported in the preset shelf without replacing the in-memory defaults.

## UI

- Brush shelf: save the current brush, import `.abr`/`.gbr` stamps, export/import the library and
  open the preset manager.
- **Preset Library** manager: rename/delete brush and gradient presets, save changes, import,
  export and reset to defaults.
- Gradient tool: apply a gradient preset, save the current gradient, and manage the library.
- Import/save errors are shown in the shelf and manager instead of being silently ignored.

## 10-bit presentation

The experimental path remains available only after enabling **Preferences → Experimental** on a
10-bit output. It is default-off, uses the GDI fallback for 8-bit documents or presenter failure,
and still lacks hardware validation for visible scanout, mixed monitors and Remote Desktop.

## Verification

- 390 Rust tests passing, 2 ignored (soak and the sparse gate).
- Formatting and Clippy correctness pass.
- Preset tests cover binary round-trip, disk save/reload, bad magic, future version, oversized
  stamp and failed-save preservation.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against the published public key before running either binary. The installer
is not Authenticode-signed; Windows SmartScreen may warn.
