# Aurelia v3.17.2

## What this release means

v3.17.2 finishes the layer-panel dirty/undo work started in v3.17.1. The panel's remaining
direct checkboxes — `Lock`, `α Lock`, `Clip`, `Ref Boundary` — and the folder selector wrote
straight to the layer, so they were invisible to `is_dirty()` (closing after a change never
prompted) and to undo. They are now discrete undo steps that mark the document dirty.

Everything else from v3.17.1 is unchanged.

## Layer panel

Undoable, one step each, and dirty by construction:

- `Lock`, `α Lock`, `Clip` and `Ref Boundary` toggles;
- assigning a layer to a folder, or moving it back to the root;
- (from v3.17.1) delete layer/folder, add layer/folder/child/adjustment, duplicate,
  mask create/invert/enable/remove, visibility and blend mode.

Known gaps still open, listed rather than implied fixed:

- **Ungrouping** marks the document dirty but has no undo step yet.
- **Continuous edits** — renaming a layer, the opacity slider, adjustment values — mark the
  document dirty but are not yet discrete undo steps.

## Verification

- 423 Rust tests passing, 2 ignored (two new: lock/clip/reference undo and dirty; folder
  membership undo).
- Formatting and Clippy correctness pass.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary.
The installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if
any, describe only the scanned artifacts and are advisory.
