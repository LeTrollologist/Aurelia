# Aurelia v3.17.5

## What this release means

v3.17.5 fixes the last defect from the audit: `scale_canvas` interpolated straight alpha, so a
transparent neighbour's colour bled into every resized edge. Bilinear canvas scaling now
interpolates premultiplied, matching the free-transform sampler. Two maintenance items from the
same checklist are included: the duplicated folder-selector egui id and the 33 `f32` literal
fallback warnings.

## Canvas resampling

- `resample_channels` keeps the historical arithmetic byte-for-byte when the four taps share
  one alpha value, so opaque scaling digests do not move (the existing baseline test still pins
  the old bytes).
- Mixed alpha is interpolated premultiplied, then unpremultiplied by the exact coverage rather
  than the rounded alpha channel. That is the same rule `sample_bilinear` applies in the
  free-transform path, and it stops a fully transparent saturated pixel from tinting a
  half-covered edge.
- Pixel-level fixtures (independent of the whole-image digest):
  - transparent saturated edge (opaque red next to transparent blue) scales to red at 50 %
    coverage (`255, 0, 0, 128`), not purple;
  - asymmetric coverage (opaque red next to half-transparent blue) gives `170, 0, 85, 192`,
    which is coverage-weighted rather than the straight-alpha `128, 0, 128, 192`;
  - the same edge on the native 16-bit path stays `65535, 0, 0, 32768`;
  - an opaque sample keeps the historical arithmetic (`105, 60, 40, 255`).

## Maintenance

- The two folder-selector combo boxes in the layer panel no longer share the `group_sel_` egui
  id; the adjustment branch and the layer branch now use distinct ids.
- The 33 `f32` literal fallback warnings are fixed with explicit `_f32` suffixes. This is a
  future-compatibility fix (they become hard errors in a later compiler) and changes no value.

## Verification

- 433 Rust tests passing, 2 ignored (four new resampling fixtures).
- Formatting and Clippy correctness pass; the workspace builds with **no `f32` fallback
  warnings**.
- The scale_canvas baseline digests for nearest and bilinear (opaque fixture) are unchanged.

## Distribution

The portable zip and per-user Inno installer are Ed25519-signed. Verify `SHA256SUMS.txt` and the
detached `.sig` files against `keys/aurelia-publisher-2026.pub` before running either binary.
The installer is not Authenticode-signed; Windows SmartScreen may warn. VirusTotal results, if
any, describe only the scanned artifacts and are advisory.
