# Aurelia v3.12.0 — interoperability, 16-bit output, brush stamps

This release collects the work that has been on `main` since v3.11.0: external clipboard breadth,
native 16-bit PNG output, the deferred layer-style semantics, brush stamp imports, a presence-log
privacy fix, and a stronger release quality gate.

## Clipboard interoperability

- **Paletted DIB decoding**: 1/4/8-bit `BI_RGB` images with colour tables, bottom-up rows,
  `biClrUsed` (or `2^bpp`), and rejection of truncated/over-claimed palettes.
- **PNG clipboard format**: copy publishes a registered `PNG` alongside DIBV5; paste prefers
  `PNG`/`image/png`, then DIBV5, then CF_DIB. PNG input checks IHDR dimensions before decoding
  (64-megapixel cap).
- Mutation corpus: every truncation and a bit flip across a paletted DIB, plus malformed DIB tests.

## Native RGBA16 PNG export

PNG export now composites at 16 bits when the document is 16-bit or contains a 16-bit layer and
writes `ExtendedColorType::Rgba16`. 8-bit documents keep byte-identical 8-bit output; JPEG/WebP
remain 8-bit. Tests prove sub-lattice values (`301/1001/40001`) survive and mixed documents export
wide.

## Deferred layer-style semantics

- **Clipping** uses the base layer's rendered alpha, including stroke/glow/shadow, in both 8- and
  16-bit compositors.
- **Scale Styles** in the resize dialog scales stroke widths, blur radii, glow radii and shadow
  offsets with the canvas (offsets per axis, lengths by geometric mean).
- **Merge Down** bakes both layers' styles and clears the lower style record, so effects are
  neither dropped nor applied twice.

## Brush stamp imports

- GIMP `.gbr` (grayscale/RGBA), Photoshop `.abr` legacy v1/v2 sampled tips (raw and RLE), and raw
  tips in modern `.abr` containers.
- Imported stamps become presets in the **Imported** category and paint with the foreground colour,
  preserving aspect ratio.
- Malformed files return structured errors. Stamps are session-only because preferences do not
  embed bitmaps; documented in [docs/BRUSH_IMPORT.md](https://github.com/LeTrollologist/Aurelia/blob/main/docs/BRUSH_IMPORT.md).

## Privacy fix: presence log

The Discord presence worker logged the update key — which included the project name — before
checking whether presence was enabled. Logging is now opt-in (`AURELIA_PRESENCE_TRACE=1`), disabled
updates write nothing, project names never enter the log, and startup removes a legacy
`presence.log` when tracing is off.

## Release engineering

- The quality gate is now `scripts/quality.py`: cargo workspace, the release tool's pytest suite,
  the ignored sparse-16-bit 0.60 gate and the 120-cycle soak.
- `verify.remote` accepts a remote branch that advanced with a normal follow-up commit as long as
  the release commit is still an ancestor; tags still require exact equality.
- Release notes links are checked for relative targets, which previously produced 404s on GitHub.

## Architecture track

The 10-bit DXGI presentation feasibility spike is in `tools/dxgi-spike`: a D3D11 FL11.1 device and
10-bit composition/HWND swapchains create and present, with the 8-bit fallback working. The
development display reports 8 bits per colour, so the visible-banding gate still requires a 10-bit
machine. See
[docs/high-bit-depth-viewport.md](https://github.com/LeTrollologist/Aurelia/blob/main/docs/high-bit-depth-viewport.md).

## Compatibility

- No AUR format change. Existing v1/v2 files remain read-only; saves write v3.
- Clipboard/DIB output remains 8-bit on the system clipboard; the internal clipboard keeps RGBA16.
- Imported brush stamps are session-only, as documented.
